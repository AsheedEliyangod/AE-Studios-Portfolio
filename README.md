## 🎮 About

This portfolio presents the game development work of AE Studios — an independent Unity developer focused on building third-person games, programming gameplay systems, and crafting interactive 3D environments.

**Core focus areas:**
- Unity game development
- C# gameplay programming
- Third-person character controllers
- Combat and interaction systems
- 3D level design and world building
- Interactive environments and atmosphere

## ✨ Portfolio Features

- **Responsive layout** — adapts cleanly from mobile to wide desktop
- **Featured Projects section** — curated preview cards with gameplay screenshots
- **Detailed Projects section** — full project breakdowns with development focus and Unity Editor screenshots
- **Filter system** — filter projects and assets by category (Games, Unity, 3D)
- **Unity Assets section** — showcases published 3D assets with Asset Store links
- **About section** — skills, tools, and development philosophy
- **Contact section** — email, GitHub, and LinkedIn links
- **Sticky navigation** — smooth scroll with active section tracking
- **Mobile hamburger menu** — fully functional responsive navigation
- **Scroll reveal animations** — elements animate in as the page is scrolled
- **Hover effects** — project cards, buttons, nav links, and social links
